# Contributing

Contributions are welcome. Open an issue first for anything larger than a small
fix, so the direction can be agreed before you invest time.

## Licence of contributions

This repository is licensed under the [MIT License](LICENSE). By submitting a
pull request you agree that your contribution is licensed under the same terms
(inbound = outbound). There is no CLA and no copyright assignment: you keep the
copyright to your work.

**Exception:** `src/KarmaWeb` is licensed under the GNU General Public License
v3.0 only (it is derived in part from Rubbergod). Contributions to that
directory are accepted under `GPL-3.0-only`. Do not copy code between
`src/KarmaWeb` and the MIT-licensed applications.

Only submit code you wrote yourself or code whose licence allows distribution
under the terms above. Do not add assets (images, icons, fonts) you do not have
the right to share.

## Dependencies

New dependencies must be permissively licensed (MIT, Apache-2.0, BSD or
similar). Do not add commercial editions (for example ag-Grid Enterprise or
CoreUI Pro) or copyleft packages to the MIT applications. List anything that
requires attribution in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

AdminWeb is the actively developed application. PrivateAdmin, PublicAdmin and
KarmaWeb are legacy and only receive fixes.
